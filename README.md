The tool itself is a prompt management and building suite. It does not provide free AI generation credits. "Unlimited" refers to the capacity to store and organize your own unlimited local prompt library. You must have an active Midjourney subscription to use the prompts you create with this tool.

### The application won't open after installation. What should I do?
